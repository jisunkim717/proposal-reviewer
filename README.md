# Proposal Reviewer

제안서 초안(PPTX)과 RFP를 함께 올리면, RFP 요구사항을 누락 없이 반영했는지 검토하고 100점 만점 점수와 등급, 개선 피드백을 보고서로 만들어 주는 Claude 스킬입니다.

## 평가 차원 (100점)

RFP 충실도 25 / 완성도 20 (목차, 콘텐츠 순서, 수행 절차, 내용) / 가독성·시각화 15 / 전문성 15 / 차별성 10 / 신뢰성 10 / 표기법·유창성 5

등급: A(90점 이상) / B(80-89점) / C(70-79점) / D(70점 미만). RFP 배점표가 있으면 평가위원 관점의 예상 점수도 함께 제시합니다.

## 구성

SKILL.md: 전체 작업 흐름

references/: 평가 기준(rubric), 맞춤법·표기 가이드, 시각요소 기준, 보고서 템플릿

scripts/analyze_pptx.py: 슬라이드별 글자 크기, 표·차트·도형, 출처 없는 수치 분석

## 사용 방법

이 저장소를 내려받아(Code > Download ZIP) Claude에 스킬로 추가한 뒤, 제안서와 RFP를 올리고 "이 제안서 RFP 기준으로 리뷰해줘"라고 요청하세요.
