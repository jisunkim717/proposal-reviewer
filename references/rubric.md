# 차원별 평가 기준 (Rubric)

각 차원은 점검 항목을 보고, 점수 구간(앵커)에 맞춰 점수를 매긴다. 앵커는 "이 정도면 이 점수대"라는 기준점이다. 그 사이 점수는 판단으로 정한다.

## 목차
1. RFP 충실도 (25)
2. 완성도 (20) — 목차 / 콘텐츠 순서 / 수행 절차 / 내용적 완성도
3. 가독성·시각화 (15)
4. 전문성 (15)
5. 차별성 (10)
6. 신뢰성 (10)
7. 표기법·유창성 (5)

---

## 1. RFP 충실도 (25점)

요구사항 매트릭스의 항목마다 판정한다.

| 판정 | 기준 |
|---|---|
| **충족** | 요구한 내용이 요구한 위치·형식으로 들어 있고, 평가위원이 바로 찾을 수 있다 |
| **부분 충족** | 언급은 있으나 깊이가 부족하거나, 엉뚱한 장에 묻혀 있거나, 요구 형식(표, 일정표 등)과 다르다 |
| **누락** | 찾을 수 없다 |
| **위반** | 형식 제약(분량, 글자 크기, 익명화 등)을 어겼다 |

점검 항목:
- 지정 목차와 장·절 순서를 그대로 따랐는가 (평가위원은 평가표 순서대로 페이지를 넘긴다)
- 과업 범위의 세부 과업이 하나도 빠지지 않고 각각 수행 방안이 있는가
- 평가 항목마다 "이 항목은 여기서 답한다"가 대응되는가. 평가 항목 명칭을 제목에 그대로 쓰면 찾기 쉽다
- RFP의 용어(사업명, 과업명, 산출물명)를 그대로 쓰는가
- 형식 제약 위반이 없는가. 분량 초과나 익명화 위반은 감점·실격 사유가 될 수 있으니 최우선으로 지적한다
- 요약서·표지·확약서 등 별도 제출물 요구가 있으면 함께 확인을 권한다

| 점수 | 앵커 |
|---|---|
| 23~25 | 누락·위반 없음. 부분 충족 1~2건, 평가 항목과 제안서 위치가 1:1로 대응 |
| 18~22 | 핵심 요구는 충족. 부차적 요구 누락 1~2건 또는 부분 충족 다수 |
| 12~17 | 과업 범위 일부 누락, 또는 목차 순서가 RFP와 크게 다름 |
| 0~11 | 필수 요구 누락이나 형식 위반이 있음, 또는 RFP와 무관한 범용 제안서 |

## 2. 완성도 (20점)

네 하위 항목을 각각 5점으로 보고 합산한다. 보고서에는 하위 항목별 소견을 따로 쓴다.

### 2-1. 목차 (5)
- RFP 지정 목차(없으면 표준 구성: 제안 개요 → 사업 이해 → 추진 전략 → 수행 방안 → 수행 관리 → 지원 사항)를 갖췄는가
- 장·절 위계가 논리적이고 번호 체계가 일관된가
- 목차 슬라이드의 제목·페이지가 본문과 일치하는가 (목차는 바뀌었는데 본문 제목은 옛날 그대로인 경우가 흔하다)

### 2-2. 콘텐츠 순서 (5)
- 왜(배경·문제) → 무엇을(목표·범위) → 어떻게(전략·방법) → 누가·언제(조직·일정) → 얼마나 잘(품질·성과) 흐름인가
- 앞에서 제시한 문제나 과제가 뒤의 해결책과 짝을 이루는가 (문제 3개를 제시했으면 해결책도 3개와 대응)
- 같은 내용이 여러 장에 중복되거나, 결론보다 세부가 먼저 나오지 않는가
- 슬라이드 제목만 이어 읽어도 이야기가 되는가

### 2-3. 프로젝트 수행 절차 (5)
- 단계(Phase)가 정의되고 단계별 활동, 산출물, 기간이 명시되는가
- 일정표(WBS·간트)가 있고 RFP의 사업 기간·마일스톤과 맞는가
- 투입 인력과 역할, 의사결정·보고 체계(착수·중간·완료 보고)가 있는가
- 위험 관리, 품질 관리, 보안, 변경 관리 방안이 있는가 (RFP가 요구하면 필수)
- 단계 간 연결(앞 단계 산출물이 다음 단계 입력이 되는가)이 보이는가

### 2-4. 내용적 완성도 (5)
- 빈 슬라이드, "TBD", "추후 작성", 자리표시자 텍스트, 템플릿 잔여물이 없는가
- 각 장이 주장만 있고 구체 내용(방법, 사례, 수치)이 비어 있지 않은가
- 기대 효과가 정성·정량으로 제시되는가
- 앞뒤 수치(인력 수, 기간, 금액)가 서로 맞는가

| 하위 점수 | 앵커 |
|---|---|
| 5 | 빠진 것 없고 흐름이 자연스러움 |
| 3~4 | 대체로 갖췄으나 1~2곳 보완 필요 |
| 1~2 | 중요한 구성 요소가 비어 있음 |
| 0 | 해당 요소가 사실상 없음 |

## 3. 가독성·시각화 (15점)

`visual-guidelines.md`의 수치 기준과 렌더링 이미지 관찰을 함께 쓴다.

점검 항목:
- **명료성**: 슬라이드당 핵심 메시지가 하나인가. 헤드라인이 주제형("추진 전략")이 아니라 메시지형("3단계 전환으로 12개월 내 안정화")인가
- **이해 용이성**: 전문 용어·약어에 풀이가 있는가. 평가위원이 30초 안에 요지를 파악할 수 있는가
- **글자 크기**: 본문 최소 크기, RFP 하한 준수, 자동 맞춤으로 과도하게 축소된 텍스트
- **텍스트 밀도**: 글로만 빽빽한 슬라이드 비율
- **도형·도식**: 프로세스·구조·관계를 도식으로 표현했는가, 도형이 장식에 그치거나 과하지 않은가
- **표**: 비교·대응 정보에 표를 썼는가, 행·열이 과하지 않은가, 머리글이 명확한가
- **그래프**: 데이터 성격에 맞는 유형인가, 축·단위·범례·출처가 있는가, 메시지를 강조하는가
- **일관성**: 폰트 종류, 색상, 정렬, 여백, 아이콘 스타일이 통일되는가

| 점수 | 앵커 |
|---|---|
| 14~15 | 거의 모든 슬라이드가 한눈에 읽히고 시각요소가 메시지를 돕는다 |
| 10~13 | 대체로 양호. 과밀·작은 글자 슬라이드가 일부(20% 미만) |
| 6~9 | 텍스트 위주 슬라이드가 많거나 시각요소가 부적절한 곳이 여럿 |
| 0~5 | 대부분 글자 벽이거나 읽기 어려움, RFP 글자 크기 하한 위반 |

## 4. 전문성 (15점)

- 발주처의 현황·문제·정책 맥락을 구체적으로 이해하고 있는가 (RFP 문구를 되풀이하는 수준인지, 그 너머를 분석했는지)
- 방법론이 이름만이 아니라 적용 방식까지 구체적인가 (도구, 프레임워크, 절차, 산출물 양식)
- 업계 용어를 정확히 쓰는가, 기술 내용에 오류가 없는가
- 유사 사업 수행 경험과 교훈이 과업에 연결되는가
- 예상 리스크와 대응을 현실적으로 짚는가

| 점수 | 앵커 |
|---|---|
| 13~15 | 발주처 맞춤 분석과 구체 방법론. 그대로 실행할 수 있어 보인다 |
| 9~12 | 방법론은 타당하나 일부가 일반론 |
| 5~8 | 대부분 범용 문구. 다른 사업에 그대로 써도 될 내용 |
| 0~4 | 과업 이해 부족, 기술 오류 |

## 5. 차별성 (10점)

- "왜 우리여야 하는가"가 앞부분(요약·전략)에서 3개 안팎으로 선명한가
- 차별점이 주장이 아니라 근거(실적, 보유 자산, 전문 인력, 고유 방법론, 수치)로 뒷받침되는가
- 차별점이 발주처의 핵심 고민(평가 배점이 큰 항목)과 연결되는가
- 경쟁사도 똑같이 말할 문구("풍부한 경험", "최고의 전문가", "고객 중심")에 기대고 있지 않은가
- 부가 제안(추가 가치)이 있다면 과업 범위를 흐리지 않는가

| 점수 | 앵커 |
|---|---|
| 9~10 | 근거 있는 차별점이 일관되게 반복·강조된다 |
| 6~8 | 차별점은 있으나 근거가 약하거나 흩어져 있다 |
| 3~5 | 차별점이 상투적 문구 수준 |
| 0~2 | 차별점을 찾을 수 없다 |

## 6. 신뢰성 (10점)

- 통계·시장 규모·성과 수치에 출처(기관, 자료명, 연도)가 있는가
- 출처가 공신력 있는가 (정부·공공기관, 국제기구, 학술지, 주요 리서치 기관 > 언론 기사 > 블로그·출처 불명)
- 자료가 최신인가 (통상 3년 이내, 빠르게 변하는 분야는 1~2년)
- 수치 간 모순이 없는가 (같은 지표가 슬라이드마다 다르게 나오는 경우)
- 자사 실적·성과 주장에 검증 가능한 근거(사업명, 기간, 발주처, 성과 지표)가 있는가
- 인용 이미지·로고의 저작권 문제 소지가 없는가
- 과장 표현("국내 유일", "최초", "100% 보장")에 근거가 있는가

| 점수 | 앵커 |
|---|---|
| 9~10 | 주요 수치 모두 출처·연도 표기, 공신력 있는 자료 |
| 6~8 | 대부분 출처 있음. 일부 누락 또는 오래된 자료 |
| 3~5 | 출처 없는 수치가 많거나 근거 없는 과장 |
| 0~2 | 수치 모순 또는 신뢰할 수 없는 출처 위주 |

## 7. 표기법·유창성 (5점)

`writing-style.md` 참고.

| 점수 | 앵커 |
|---|---|
| 5 | 규범 오류 거의 없음(3건 이하), 용어 통일, 문장 자연스러움 |
| 4 | 규범 오류 소수, 일부 표기 불일치 |
| 2~3 | 반복되는 맞춤법·띄어쓰기 오류, 번역투·비문 다수 |
| 0~1 | 오류가 많아 전문성 인상을 해침 |

## RFP 배점 기반 예상 점수

1. 평가표의 정성 항목마다, 위 차원 평가에서 얻은 근거를 해당 항목에 매핑한다.
2. 충족 수준을 RFP 척도(없으면 수 100% / 우 90% / 미 80% / 양 70% / 가 60%)로 판정한다.
3. `예상 득점 = 배점 × 달성률`. 판정마다 한 줄 근거를 단다.
4. 정량 항목(실적, 인력 자격, 재무, 가격)은 제안서만으로 알 수 없으면 "판단 불가"로 둔다.
5. 정성 항목 합계와 "어느 항목을 한 단계 올리면 몇 점이 오르는지"를 함께 보여준다. 사용자가 노력을 어디에 쓸지 정하는 데 가장 쓸모 있는 정보다.
